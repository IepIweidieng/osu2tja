[TimingPoints] timing section

format：
time,beatLength,(v4+)meter,(v4+)sampleSet,(v4+)sampleIndex,(v4+)volume,(v4+)uninherited,(v5+)effects

v8 example:
125,598.802395209581,4,1,0,100,1,0

time: 125 --> time offset (ms)
beatLength: 598.802395209581 --> 每拍长度毫秒数，  duration per beat (ms),
    如果为负数 x，则 scroll 倍数为 -100/x  for negative value x, the scroll multiplier is -100/x
meter: 4 --> 每小节的拍数  beats per bar
sampleSet: 1 --> 1:normal 2:soft  (v14?: 0:beatmap default  3:drum)
sampleIndex: 0 --> 0:default 1:custom1 2:custom2
volume: 100 --> volume
uninherited: 1 --> 1:红线  red line  0:绿线  green line
effects: 0 --> 1(v14: &1=1):kiai ==> Go-Go Time  (v14?: &8=8:略过首小节线  omit first barline ==> barline off/on)

SCROLL SPEED: BPM 越高 scroll 速度越快，绿线同样处理
  The higher the BPM, the faster the scroll speed. Same treatment for green lines

[HitObject] Note

hit object type ※:
	&1 = 1:circle
	&2 = 2:slider
	&1<<2(=4) = 4:new combo
	&8 = 8:spinner

hitSound ※: 4:finish, 8:clap
	1<<2:finish
	1<<3:clap

	don: 0
	ka:  1<<3 = 8
	big don:1<<2 = 4
	big ka:1<<2 + 1<<3 = 12
	黄条  yellow bar roll:slider with sound = 0
	大黄条  big yellow bar roll:slider with hit sound = finish
	气球连打  balloon roll：spinner


Circle format:
x,y,time,type(type&1=1),hitSound,(v11+)hitSample

v8 example:
416,176,1921,1,4
v11 example:
256,352,3925,1,0,0:0:0


Slider format:
x,y,time,type(type&2=2),hitSound,curveType|curvePoints(x:y),slides,length,(v8+)edgeSounds,(v11+)edgeSets,(v11+)hitSample
line_type(L=linear, C=centripetal catmull-rom (deprecated), B=bézier, (v11?)P=perfect circle)

v8 example:
332,267,105214,2,4,L|160:224,1,161.000005277991,0|0
v11 example:
308,64,2725,2,0,P|424:88|424:208,1,240,4|8,0:0|0:0,0:0:0

slider length:
length * slides = 100 * (拍数  beat count) * slider_velocity * scroll_muliplier
super mario bros.(Old)
length = 100 * 1 * 1.4 * 1.15 / 1= 161

特殊规则，2 拍 (v1~7: 再除以 scroll) 內 slider 转 notes（taiko 模式除外）
Special rule, slider less than 2 beats (v1-7: ... divided by scroll) to notes (except for taiko mode)


Spinner format:
x,y,time,type,hitSound,endTime,(v11+)hitSample

v8 example:
256,192,119684,12,0,120882
v11 example:
256,192,12475,12,4,17125,0:2:0
